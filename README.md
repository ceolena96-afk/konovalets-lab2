# Лабораторна робота №2 — Git, GitHub та GitHub Pages

Навчальний сайт про Євгена Коновальця з лабораторної роботи №1.

Авторка: Чернякова Олена, група ТР-51.

## Мета

Навчитися зберігати зміни за допомогою Git, створювати й об’єднувати гілки та опублікувати готовий сайт на GitHub Pages.

У завданні ЛР2 окремих варіантів немає. Використовується власний проєкт з ЛР1.

## Склад проєкту

- `index.html` — біографія Євгена Коновальця.
- `gallery.html` — фотоархів.
- `contact.html` — навчальні форми.
- `CSS/styles.css` — спільне оформлення сторінок.
- `CSS/ornament.png`, `images/` — локальні зображення.
- `ДЖЕРЕЛА.md` — джерела тексту та зображень.
- `КОНТРОЛЬНІ_ПИТАННЯ.md` — відповіді для захисту ЛР2.
- `.nojekyll` — публікація готових файлів без обробки Jekyll.

## Локальний перегляд

Відкрити `index.html` у сучасному браузері. Усі сторінки, стилі та зображення потрібно залишити у відповідних папках. Збірка та встановлення залежностей не потрібні.

## Особливості сайту

Проєкт використовує HTML5 і CSS. Форми демонструють браузерну перевірку полів: реєстрація, вхід і надсилання повідомлень на сервер не виконуються. Для демонстрації слід використовувати вигадані дані.

Посилання на сторінки та ресурси відносні, тому сайт можна розмістити в підпапці GitHub Pages.

## Що показати на захисті

1. Файли сайту й локальний репозиторій.
2. Історію кількох комітів: `git log --graph --oneline --all`.
3. Створену гілку та коміт її злиття з `main`.
4. Репозиторій на GitHub.
5. Сайт, опублікований через GitHub Pages, і переходи між трьома сторінками.
