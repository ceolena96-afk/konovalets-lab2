# Звіт до лабораторної роботи №2

**Тема:** використання Git та GitHub для вебпроєктів.

**Виконала:** Чернякова Олена, група ТР-51.

**Дата:** 1 листопада 2026 року.

## Мета

Опанувати збереження версій у Git, створення й об’єднання гілок, роботу з віддаленим репозиторієм та публікацію статичного сайту через GitHub Pages.

## Вихідний проєкт

Використано власний мінісайт із ЛР1 про Євгена Коновальця: біографія, фотоархів і сторінка навчальних форм. Сайт написано на HTML5 і CSS. Окремих варіантів у завданні ЛР2 немає.

## Виконані дії

1. Створено окрему копію проєкту та локальний репозиторій: `git init -b main`.
2. Налаштовано авторку комітів у цьому репозиторії. Для пошти використано адресу GitHub `noreply`.
3. Створено початковий коміт із сайтом і наступний коміт з описом роботи та `.gitignore`.
4. Створено гілку `feature/github-pages` командою `git switch -c feature/github-pages`.
5. У цій гілці додано `.nojekyll` і відповіді на контрольні питання, зміни збережено окремим комітом.
6. Виконано перехід до `main` та явне злиття: `git merge --no-ff feature/github-pages`.
7. Створено публічний репозиторій на GitHub та додано його як `origin`.
8. Обидві гілки завантажено командою `git push -u origin main feature/github-pages`.
9. Для GitHub Pages вибрано гілку `main` і корінь репозиторію `/`.

## Перевірка

- Перевірено 3 HTML-сторінки та 98 локальних посилань на сторінки, розділи й ресурси: відсутніх цілей не знайдено.
- Використано відносні шляхи з урахуванням регістру назв папок, зокрема `CSS/styles.css`.
- `index.html` розташований у корені репозиторію.
- Зображення та стилі зберігаються разом із сайтом; встановлення залежностей і збірка не потрібні.
- Обидві гілки надіслано у віддалений репозиторій, коміт злиття збережено в історії.

Форми є навчальними: перевірка полів відбувається в браузері, а створення акаунтів і передавання даних на сервер не реалізовано.
